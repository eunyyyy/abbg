# ai-landingpage

레퍼런스 URL(+회사 정보) 입력 → AI가 생성한 랜딩페이지를 업종 카테고리별로 분류해 보관하는 폴더입니다.

## 작업 흐름

1. **입력**: "레퍼런스 URL"만, 또는 "레퍼런스 URL + 회사 정보"를 전달받는다.
2. **로컬 준비**: 로컬 X31 드라이브의 아래 두 자료를 기준으로 삼는다.
   - `0. 선행되어야 하는 자료/디자인 감도 올리는 파일/` — `CHEATSHEET_18_EN.md`(빌드 방법론) + `styles.css`(마스터 디자인 토큰). 신규 프로젝트는 이 파일을 복제해서 시작한다.
   - `0. 선행되어야 하는 자료/카테고리별 이미지 소스/` — 업종/테마별 실사 이미지·영상 소스 라이브러리 (교육, 라이프스타일, 모빌리티, 바이오, 반도체·전력, 실내, 에너지·자원, 여행, 유통·물류, 이펙트, 지구, 축산업 등).
   - `0. 랜딩페이지 프롬프트 샘플.rtf` — 아래 "빌드 규칙"의 원본.
3. **빌드**: "랜딩페이지 작업" 폴더 안에 다음 순번 `n.기업명` 폴더를 새로 만들어 로컬에서 작업한다 (빌드 규칙 준수).
4. **완료 후 업로드**: 완성된 랜딩페이지를 업종에 맞는 카테고리 폴더 하위에 `n.기업명/` 형태로 그대로 커밋해 이 저장소(`ai-landingpage`)에 저장한다.

## 빌드 규칙 요약 (`0. 랜딩페이지 프롬프트 샘플.rtf` 기준)

0. 레퍼런스 URL 입력 시 레퍼런스와 동일한 디자인 + 가상의 기업 정보를 생성해 아래 순서로 진행한다.
1. "0. 선행되어야 하는 자료"의 기본 템플릿 파일을 복제한다.
2. "랜딩페이지 작업" 폴더 안에 `n.기업명` 이름으로 생성한다.
3. 제작 전 카테고리 1개를 위 9종 중에서 선택해 가상의 기업 정보를 생성한다.
4. GNB는 영문/국문 중 하나만 노출한다.
5. 서체는 레퍼런스와 동일하게(없으면 최유사 웹폰트로, noonnu.cc / fonts.google.com) — 메인 폰트 + 본문 폰트 최대 2종만 사용.
6. 컬러는 프라이머리 10단계·세컨더리 10단계, 그레이스케일은 프라이머리의 웜/쿨 계열에 맞춰 12단계 — 사용 컬러는 1~3개로 제한.
7. 레퍼런스와 동일/유사한 이미지로 교체한다.
8. 모든 텍스트에 의미 없는 언더바(`-`)를 사용하지 않는다.
9. 반응형은 데스크탑 비율 그대로 모바일에 리사이징. 데스크탑 본문 16px 이상(14px 미만 금지, 주석/푸터 예외). 모바일 본문 15~16px, 화면 너비에 비례 리사이징.
10. 모바일 뷰는 가로 768px 미만.
11. 헤더/푸터/바디의 좌우 여백은 풀블리드 예외 섹션을 제외하고 동일하게 적용 (모바일 좌우 15px 기준).
