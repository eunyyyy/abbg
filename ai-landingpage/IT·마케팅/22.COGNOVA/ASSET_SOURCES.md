# Asset sources

- `img/clipart-network-sphere.jpg` — ClipartKorea membership asset `psxtg403145`, downloaded 2026-09-26 from the logged-in `alphabrother` account. Used as a contained hero texture; the site-wide logo, orbit system, cards, and project graphics are original SVG/CSS artwork.
- Pinterest was used only as a visual research source for color, editorial grid, type scale, and interaction direction. No Pinterest artwork is embedded in the site.
- `img/cognova-mascot.png` — sourced from a user-provided reference image (yellow star character), background removed and recolored to brand lime (#C8FF3D) programmatically via PIL/numpy, not from Clipart Korea.
- Card/section badge icons (asterisk, burst, blob, dots-cluster, squiggle-arrow) in Services/How-We-Move/Work are original inline SVG symbols authored to match the sticker-badge mood board the user attached (Pinterest refs), not sourced from Clipart Korea — flagged as a substitution since that would have required a live, user-driven Clipart Korea login this session didn't have.
